# BUG-004 저장 대화상자의 "Save to file" 버튼 글자 대비 부족(2.43:1)

| 항목 | 내용 |
| --- | --- |
| 상태 | 업스트림 미수정(기존 이슈 없음, 초안만 작성) |
| 심각도 | Minor |
| 우선순위 | P3 |
| 발견일 | 2026-10-30 |
| 발견 테스트 | `tests/e2e/a11y.spec.ts` (axe `color-contrast`) |

## 환경

- Excalidraw `v0.18.1` 프로덕션 빌드(`vite preview`), Windows 11, 라이트 테마
- Playwright 1.64.1: Chromium 156.0.8078.4, Firefox 157.0, WebKit 27.2, 뷰포트 1280x720
- 3개 브라우저 모두 재현

## 재현 순서

1. 앱을 열고 도형을 하나 그린다.
2. 메뉴 > Save to... 를 연다.
3. "Save to disk" 카드의 "Save to file" 버튼 글자 대비를 측정한다(axe 또는 대비 측정 도구).

## 기대 결과

일반 크기 글자(16px, 보통 굵기)의 대비가 4.5:1 이상(WCAG 2.1 1.4.3 AA).

## 실제 결과

글자 `#ffffff`, 배경 `#74b816`, 대비 **2.43:1**(axe 측정값). 같은 대화상자의 다른 카드 버튼은 이 검사에서 위반이 나오지 않았습니다.

## 원인(코드 분석)

`JSONExportDialog.tsx`가 `<Card color="lime">`를 쓰고, `Card.tsx`는 버튼 배경을 `OpenColor.lime[7]`(`#74b816`), `Card.scss`는 글자를 흰색으로 고정합니다. OpenColor lime 계열은 9단계(`#5c940d`)도 흰 글자와 3.69:1이라 배경 단계만 바꿔서는 기준을 맞출 수 없습니다.

## 영향 범위

저시력, 색각 이상 사용자. 파일로 저장하는 주요 버튼의 글자를 읽기 어렵습니다. 기능 자체는 동작합니다.

## 업스트림 이슈

같은 이슈를 찾지 못했습니다(검색어: 'contrast "Save to file"', "color contrast button", "contrast save"). Deque 감사 이슈 [#7492](https://github.com/excalidraw/excalidraw/issues/7492)의 Issue 6도 대비 문제지만 다크 테마의 힌트 글자(`.HintViewer`)에 관한 것이라 다른 결함입니다. 아래 초안만 작성하고 올리지 않았습니다.

### 이슈 초안(미등록)

> **a11y: "Save to file" button text contrast is 2.43:1**
>
> Version: v0.18.1 (`<Card color="lime">` unchanged on `master` as of 2026-10-30). Light theme.
>
> Steps: draw a shape, Menu → Save to… Check the "Save to file" button.
> Expected: ≥ 4.5:1 for 16px regular text (WCAG 1.4.3 AA).
> Actual: white `#ffffff` on `#74b816` (`OpenColor.lime[7]`) = 2.43:1 (axe-core `color-contrast`).
>
> No lime shade reaches 4.5:1 with white (lime[9] = 3.69:1). One option: dark label text on lime cards (`gray[9]` on `#74b816` passes); patch attached.
